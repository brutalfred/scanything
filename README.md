# Scanything

**Scan anything — Know everything.**

Scanything is an AI-powered camera scanner that analyzes everything in the room bigger than an apple using fast, low-power AI. Tap any detected item for expanded information, official product links, and price-range estimates.

## Features

- **Room Scan** — Live camera analysis with interactive bounding boxes for every detected object
- **Document Scan** — OCR text extraction with AI summarization and translation into 27 languages
- **Authenticate Luxury Items** — AI-guided authenticity checks for handbags, watches, and more
- **One-tap Resale Listings** — Generate resale drafts with price estimates for global and regional marketplaces
- **Offline Scan Queue** — Queue scans when offline and process them later
- **Multi-page Document Stitching** — Combine multiple scans into one document
- **Collections & Tags** — Save scans to organized collections
- **Ask AI** — Ask follow-up questions about any detected object
- **Shareable Scan Cards** — Export scans as social-media-ready images
- **Credits System** — Earn credits via daily check-ins, referrals, and rewarded ads
- **Themes** — Multiple color themes including the default Cyber theme
- **27 Languages** — Full interface localization with automatic RTL support

## Scan Modes

| Mode | Description |
| --- | --- |
| Room | Live object detection with bounding boxes |
| Document | OCR text extraction + summarization |
| Authenticate | Luxury item authenticity analysis |

## Pricing

- **Free** — Limited daily scans
- **Pro ($9.99/mo)** — More scans, lower credit costs
- **Max ($19.99/mo)** — Unlimited features, lowest costs

In-app credit packs and subscriptions are processed via Google Play Billing on Android.

## Pi Network Integration

Scanything supports **Pi Network** authentication and payments when opened in the Pi Browser:

- Pi Sign-In with username scope
- U2A credit-pack purchases paid in Pi
- Automatic Pi exchange-rate pricing
- Referral rewards for Pi users

Outside the Pi Browser, the app uses Google/email authentication and Google Play Billing.

## Tech Stack

- **Framework:** TanStack Start (React 19, SSR)
- **Styling:** Tailwind CSS v4
- **Backend:** Lovable Cloud (Supabase) with Row-Level Security
- **AI:** Google Gemini (2.0 Flash for scanning, 2.0 Pro for authentication)
- **Mobile:** Capacitor (Android / Google Play)
- **Payments:** Google Play Billing, Pi Network
